MUSTI RACING - PSP HOMEbrew
===========================

Dosyalar:
- main.c     : Oyunun C kaynak kodu
- Makefile   : PSPSDK derleme ayarlari
- README.txt : Bu dosya

Derleme:
1. PSP Developer ortaminda PSPSDK kurulu olmali.
2. Bu klasorde terminal ac.
3. make komutunu calistir.
4. Derleme basarili olursa EBOOT.PBP olusur.
5. EBOOT.PBP dosyasini PSP/GAME/MUSTIRACING/ klasorune koy.
6. PSP veya PPSSPP uzerinden oyunu baslat.

Kontroller:
- Sol / Sag yon tuslari: Serit degistir
- X: Hizlan
- O: Fren
- START: Kaza sonrasi yeniden baslat
- HOME: Oyundan cikis menusu

Not:
Bu arsiv kaynak kodlarini icerir; EBOOT.PBP hazir olarak dahil degildir.
Derleme icin PSPSDK gerekir. Bu ilk surum, PSP'nin metin ekranini kullanarak
calisan basit bir trafik kacis prototipidir.
